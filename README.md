# Site público do Iron Fit Core

Site estático para `ironfitcore.com.br`, baseado na página do Iron Fit da FM Tecnologia IA. O aplicativo é acessado em `https://app.ironfitcore.com.br/`.

## Prévia local

Execute `python3 -m http.server 8000` na raiz e abra `http://localhost:8000/`.

## Publicação

Sirva a raiz deste repositório no host do site público. O site não exige build. A página inicial é `index.html` e a versão web e o PDF do manual ficam em `assets/manuais/`.
